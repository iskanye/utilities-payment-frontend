Добро пожаловать в сервис оплаты ЖКХ

Это фронтенд-приложение для работы с API микросервисного приложения оплаты коммунальных услуг. Вы можете управлять своими счетами, производить оплату и администрировать систему.

Аутентификация

Зарегистрируйте новый аккаунт или войдите в существующий для доступа к функциям системы.

Регистрация

Вход

Регистрация

Создайте новый аккаунт, указав email и пароль. После регистрации вы сможете войти в систему.

Вход

Используйте свои учетные данные для входа в систему. После успешного входа вы получите токен авторизации.

Безопасность

Ваш токен сохраняется локально в браузере. Не передавайте его третьим лицам.

Счета

Просматривайте и оплачивайте свои счета за коммунальные услуги.

Мои счета

Поиск и оплата

Мои счета

Нажмите «Загрузить все счета», чтобы увидеть список всех ваших счетов за коммунальные услуги.

Поиск счёта

Введите ID счёта, чтобы найти конкретный счёт и просмотреть его детали.

Оплата

Введите ID счёта, который хотите оплатить, и нажмите кнопку «Оплатить».

Админ-панель

Доступно только для пользователей с IsAdmin = true.

Выставить счёт

Список пользователей

Создание счёта

Выставляйте счета пользователям за коммунальные услуги. Укажите адрес, сумму и ID пользователя.

Управление пользователями

Просматривайте список всех зарегистрированных пользователей и их статусы администратора.

Важно

Для доступа к функциям админ-панели ваш аккаунт должен иметь права администратора.
